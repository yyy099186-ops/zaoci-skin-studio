造次 Zaoci · 游戏皮肤工作台

把「风格技能」变成成套小游戏 UI 设计方案的可视化工作台。上传参考图、填主题参数、一键攒出设计任务，右侧同步产出品牌色彩系统、关键词分析与世界观扩写。

打开网址 https://zaoci-skin-studio.vercel.app/

1先看一眼三栏布局

打开网址后是一个从左到右的三栏工作台，各司其职：

左栏 · 输入 & 参数
上传三类参考图、填主题 / 风格 / 角色一致性，底部选风格技能。
中栏 · 6 格出图画布
主界面 / 关卡 / 战斗 / 结算 / UI 组件 / 配色板，成套呈现。
右栏 · 分析
品牌色彩系统 + 关键词分析 + 世界观扩写，随参考图产出。
现在打开就有东西看
网址里已经带了一套「金克丝 × 海岛探宝」的示例：中栏 6 张真图、右栏真取色的品牌色系 + 2 套世界观。第一次打开直接看这套就能明白工作台长什么样、能产出什么。

2上传参考图 — 三个槽各有分工

这是最关键的一步。三个上传槽不是随便放，每个槽喂给工作台的信息不一样：

① 配色 & 品牌 DNA

定调子

放主角 / 主视觉。工作台从这张提取配色、提炼品牌气质，决定整套方案的色彩系统和世界观基调。

② 图形元素

定造型

放你想复用的图形 / 图标 / 装饰母题。工作台参考它的形状语言，让按钮、边框、道具风格统一。

③ 玩法

定框架

放你参考的玩法 / 界面结构截图。工作台参考它的信息布局，安排 6 格界面的功能分区。

三个槽不必全填，至少放 ① 配色&DNA 那张，出来的方案质量最高。

3填参数 → 点「生成」

上传完参考图，在左栏把这几项填一下，然后点底部的生成按钮：

  1. 主题：一句话说清这套皮肤的主题，例如「夏日海岛探宝」「赛博电音节」。
  2. 风格技能：在左栏底部选一个已内置的风格（如「街头二次元可爱风」），它决定画风 / 描边 / 组件几何。
  3. 角色一致性：勾上后会锁定 ① 号参考图里的角色，整套图都用同一个人，不会画成另一个。
  4. 点 生成：工作台会把你所有输入攒成一份任务文件 job.json 并自动下载到你电脑。

4真图和真分析怎么出来 — 请务必读这段

⚠ 点「生成」不会当场凭空冒出你新传那套图的真图真分析
因为「按参考图真出图、真取色、写世界观」是 AI 模型能力，不在网页浏览器里。网页负责上传、填参、预览、把任务打包成 job.json；真正出图和分析这一步，现阶段由 miko 在助手里代跑。

5各角色能做什么 · 一图看懂

你（组员 / 设计师）在网址上

  • 填主题 / 选风格 / 勾角色一致性
  • 点生成，拿到 job.json 任务文件
  • 预览已出的示例真图和分析
  • 点生成后当场凭空出你那套的真图真分析
出真图真分析（现阶段）

  • 助手真调三谦出成套图
  • 对参考图真取色、写 2+ 套世界观
  • 结果回填，刷新网页即显示
  • 无需你懂任何代码

6常见问题

  1. 打开是空白 / 图裂？ 刷新一次；确认网络能访问 vercel.app 域名。
  2. 点生成没反应？ 它其实已经把 job.json 下载到你电脑了，去下载文件夹找一下，把它发给 miko 即可。
  3. 我上传的图为什么没变成成品？ 见第 4 步——真出图这一步现阶段要发 miko 代跑，不是网页当场生成。
  4. 手机能打开吗？ 能，但三栏工作台在电脑上体验最佳，建议用电脑操作、手机看预览。
